# 获取帮助 / Support

## 使用问题

先查看[使用指南](docs/usage.md)中的安装、配置、数据位置和常见问题。如果问题仍然存在，请搜索
[已有 issue](https://github.com/hanshanyike/dsh-yolo/issues)，再使用缺陷报告表单提交可复现信息。

Start with the installation, configuration, data-location, and troubleshooting sections in the
[Chinese user guide](docs/usage.md). If the problem remains, search
[existing issues](https://github.com/hanshanyike/dsh-yolo/issues) before opening a reproducible bug report.

## 功能建议

请先阅读[产品愿景](docs/VISION.md)。功能建议应说明需要解决的管理问题、理想结果和成功标准；
YOLO 的边界是管理而非替用户执行。

Read the [product vision](docs/VISION.md) first. Feature requests should explain the management problem,
desired outcome, and success criteria; YOLO manages work instead of executing it for the user.

## 安全问题

不要在公开 issue 中披露漏洞、密钥或私人数据。请按[安全政策](SECURITY.md)使用私密报告渠道。

Do not disclose vulnerabilities, keys, or private data in a public issue. Follow the private reporting
path in [SECURITY.md](SECURITY.md).
